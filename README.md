# Christina Maria D’costa — Portfolio

A modern, elegant, and responsive personal portfolio showcasing Christina Maria D’costa’s professional journey, experience, and skills across client services, business development, sales, and marketing.

**Features**
- Modern, minimalist design
- Responsive layout
- Professional experience and education sections
- Skills and career highlights
- Clean typography and elegant color palette

**Purpose:** To establish a professional online presence and showcase career experience and capabilities.
